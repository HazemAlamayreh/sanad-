# Sanad Study Dashboard

A browser-based Grade 8 study planner with daily task tracking, progress and XP rewards, backup/restore, and selectable weekly A4 PDF reports.

## Open the dashboard

After enabling GitHub Pages, open the published Pages URL. The app is a static `index.html` file and runs in the browser.

## Data and privacy

Task completion changes are saved in the browser's local storage. Export a JSON backup periodically. This repository is currently public, so anyone can view the dashboard source and the study schedule included in it. Consider switching the repository to Private if you do not want the schedule publicly visible.
